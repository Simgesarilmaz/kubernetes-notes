## 🔑 Anahtar Kavramlar (dinlerken dikkat et)
- **Label** — kaynaklara takılan key-value etiketler
- **Selector** — etiketlere göre kaynak seçme
- **Annotation** — metadata (selector'da kullanılmaz)
- Servis ve Deployment'ların pod'ları nasıl bulduğu
- `kubectl get pods -l app=web` (label ile filtreleme)
- `kubectl label` komutu
