## 🔑 Anahtar Kavramlar (dinlerken dikkat et)
- Service neden gerekli? (pod IP'leri değişken)
- **ClusterIP** — cluster içi (varsayılan)
- **NodePort** — node üstünden dışarı (30000-32767)
- **LoadBalancer** — bulut LB ile dışarı
- **ExternalName** — DNS CNAME
- Service ↔ Pod selector ilişkisi, Endpoints
- Cluster içi DNS: `servis.namespace.svc.cluster.local`
